# Simple Calculator

A simple calculator built using HTML, CSS, and JavaScript.

This project performs basic arithmetic operations like:
- Addition
- Subtraction
- Multiplication
- Division

It also includes:
- Dark theme UI
- Delete button
- Clear button

---

# Technologies Used

- HTML
- CSS
- JavaScript
